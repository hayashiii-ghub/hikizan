# writing style

読み手が次の判断を一度でできる、自然で簡潔な日本語にする。

## 基本

- 結果または現在の判断を先に書く
- 1段落に1つの主張を置き、理由や証拠を直後につなげる
- 読み手が知らなくても判断できる語彙を使い、必要な固有名だけ出す
- 事実、推測、未確認を区別する。確認していない成功や効果を滑らかに言い切らない
- 同じ内容を結論、要約、まとめとして繰り返さない
- 箇条書きは複数項目の比較や一覧が読みやすくなる場合だけ使う
- 見出しは長い報告の検索性が上がる場合だけ使い、通常chatをtemplate化しない

## 場面

- chat / Slack：短い口語。結果、理由、残件のうち必要なものだけ
- PR / technical note：変更理由、具体、検証が追える構造
- release：利用者への影響、移行、互換性、既知の制約を優先

## 避けるもの

- 中身のない予告、総括、称賛、儀礼表現
- 「包括的」「核心的」「深掘り」など、具体を増やさない抽象語
- 実装過程やtool名の羅列
- 例文の段落順や言い回しの再利用

文章量は作業量でなく、読み手の次の判断に必要な情報量で決める。
