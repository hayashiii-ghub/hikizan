# 認知リズムを生むための日本語ライティング規範

密度の高い文章が退屈になるのは、情報が多いからではなく、全文が同じ認知モードで書かれているからである。
この規範は、読者の認知モード (観察する、迷う、確信する、確かめ直す) を意図的に切り替え、「続きを読む理由」を維持することで読み進める推進力を作る。

## 適用範囲と優先関係

作業前に `writing-style.md` を読む。
技術記事、書籍の章、読み物として順に読ませる長い解説、または平坦さや緩急を直すよう明示された文章にだけ、この規範を追加で適用する。
PR 本文、作業報告、通常の README、短い説明では `writing-style.md` だけを使う。

論証の正確さ、事実の保持、読者への誠実さ、冗長の排除は `writing-style.md` を優先する。
読者の疑問は問いとして置いてよいが、想像上の読者との問答は作らない。
語り手の逡巡、思い込み、告白は、原稿や資料に実在する判断状態だけを使う。
事実や判断状態に材料がなければ、緩急を作るために捏造せず、平坦なまま残す。

## 基本原理

- 緩急は情報量の増減ではなく、認知モードの切替として設計する。観察→逡巡→断定→再観察の往復が一つの単位である。
- 文章は常に、少なくとも一つの**未回収の緊張** (答えの出ていない問い、裏の取れていない確信、あとで返すと約束した答え) を開いておく。緊張がすべて閉じた瞬間、読者は読むのをやめられる。
- 完成した結論を解説する声ではなく、考えながら進む当事者の声で書く。書き手が答えに至る過程の再演が、読者の思考の再演になる。
- **生成側の制約**：拍、緊張、緩みの材料は、対象世界の出来事、データ、発言、語り手の判断状態からしか取らない。状況に材料が見つからない位置には何も足さない。本文自身を話題にした文 (「〜の列挙はしない」「問いは〜だけである」) でリズムを作らない。新造・整形した文は、書いた時点で「緩みと駄文の見分け方」の判定にかける。
- **装置は実現し、宣言しない**：この規範の装置名、手順、例文 (「答えの半分」「緊張」「回収」「問いを半分ずつ返す」など) を本文に書かない。「問いを半分ずつ返す」は、答えの前半を内容として書くことで実現する。「先に答えを半分だけ置く」のように操作を宣言した文は削る。
- **場面のない説明文での状況**：物語の場面を持たない解説では、対象そのものの性質 (データ、計算、トレードオフ、素朴な期待が事実に破られること) と、読者が抱く推論・反問から緊張を作る。本文の進行を語ることで緊張を代用しない。
- **短文化バイアスを避ける**：拍を作るために文を削らない。導入に必要な範囲、観点、比較軸、未確定事項を削って短くするのは、緩急ではなく欠落である。密度を上げる編集は、共有済み文脈の上でだけ行う。

## 文の拍

- 短文で足場を打ち、長めの文で流し、短文で止める。「立てる→流す→止める」を段落の基本拍にする。
- 断定だけで押し切らず、断定と根拠のある逡巡を交互に置く。
  - 断定：「〜だった」「〜である」「〜というわけだ」
  - 逡巡：「〜に違いない」 (あとで事実に裏切られる実在の思い込み)、「〜とは思う。ただ…」「〜だろうか」
- 「あとで事実に裏切られる確信」は、読者の予測を誘導してから崩す布石になる。ただし、実在しない思い込みを作らない。
  - 例：「うまくいっているに違いない。」→ (次の段落で)「ところが、あとになって記録を見ると、そうではなかった。」
- 転回点では「譲歩→転回→短い停止」の拍を使える。転回後の短い指示文で、読者の視線を固定する。

## 段落の密度波形

- 密な段落が2〜3個続いたら、疎の段落を1つ置く。疎の段落の機能は、確定事項の一行固定、次の判定対象の提示、視点距離の切替のいずれかに限る。
- 視点の距離を固定しない。具体 (記録、数値、発言、コード) に寄る段落と、意味づけで一段引く段落を交互に置く。
- 箇条書きは情報の圧縮だけでなく、本文の呼吸を止める「間」としても使える。列挙のあとの一段引いた文は、この間があるから効く。

## 冒頭の設計

- 最初の数文で未回収の緊張を一つ作る。型は問わない。
  - 読者の実感の言い直しから仮説へ進む
  - 読者へ直接問いかけ、置き去りにせず自分の答えを返す
  - 確信を帯びた一般命題を置き、あとの本文でその確信を試す
  - 語り手の実在する思い込みを書き切り、事実で崩す
  - 前章・前節が残した問いを、当事者の言葉で言い直す
- 読み物プロファイルでは、結論そのものを一文目に置かなくてよい。ただし、第一段落で対象と論点を特定する。
- 予告や要約は禁止しない。態度のある一〜二文なら、それ自体が緊張を作れる。態度のない議題表 (「本章では A、B、C を扱う」) は避ける。
- 読者が抱く抵抗 (古い、作為的、実用性がない、自分には関係ない) は、具体的な反論として先に示し、短く処理してから本題に入る。

## 節の入り方

- 節の頭で「本節では〜を扱う」と宣言しない。代わりに次のいずれかで入る。
  - 直前の節が残した違和感を、当事者の問いとして言い直す
  - 読者が当然抱く反問をそのまま書き、一度受けてから崩す
  - 資料に裏づけられた書き手の告白から入り、直後の論証の足場にする
- 理論、概念、引用は、読者の中に「まだ名前のない違和感」を作ってから導入する。理論は答えではなく命名として入れる。
- 節と節の橋は、前節の末尾ではなく次節の頭に置く。前節末に「次は〜を見る」と予告せず、次節の頭を反問、違和感、告白で開く。

## 列挙の着地

- 性質や分類を列挙したら、各項目を直前の具体的な場面へ一つずつ着地させる。
- 着地の文体は均一にしない。正体の指摘、身に覚え、固有の事実への対応づけ、未来の断念と変化をつける。

## 問いの回収と結び

- 途中で立てた問いは放置せず、明示的に回収する。答えを段階的に返すと、後半の推進力になる。
- 積んだ抽象を、読者がすでに持っている具体 (冒頭の場面、読者自身の経験、序盤の問い) へ着地させてから閉じる。抽象論や一般則のまま終えない。
- 緊張は選んで閉じる。最後に一つだけ開いたまま残してよい。
- 二人称の呼びかけ、読者への依頼、書き手の謙抑や断りは、章の冒頭・結びなどの境界に限る。中盤の論証に混ぜない。

## 緩みと駄文の見分け方

判定の軸は一つである。
**その文が更新するのは「状況」か、「文書」か。**

- **状況を更新する文**：対象世界の出来事、データ、人物の発言、または語り手の判断状態 (思い込み、保留、後悔、譲歩、告白) を新しく伝える。緩みとして残してよい。
- **文書を更新する文**：この章、この節、この説明、ここまでの話がどう見えるか、次に何を書くかだけを伝える。原則として削除する。

駄文の典型は次のとおりである。

- 「ここまでだと、概念の説明に見えるだろう。なので、すぐに例へ戻す。」 (説明の見え方と執筆の予定)
- 「要するに、この章の主題は〜ではなく〜である。」 (章の性格づけの言い直し)
- 「誤解しないでほしいのだが、〜を否定したいわけではない。」 (退ける誤読を特定しない弁明)
- 「テクニックの列挙はしない。」 (本文の性格・範囲の宣言)
- 「先に答えを半分だけ置く。」 (この規範の装置の実況)
- 「ここまでで〜は見えた。次は〜を見る。」 (節末の進行予告)

駄文は短い断定の形でも現れる。
文書更新の文を短く断定調へ整形すると、拍が効いた決め台詞に見えて残りやすい。
短くてリズムがよいことは、残す理由にならない。

良い緩みは、状況か語り手の実在する判断状態を更新する。

- 「うまくいっているに違いない。」 (あとで崩される実在の思い込み)
- 「まあ、今すぐ手を打つほどでもないのだけど、どこかの時点で整理は要るだろう。」 (判断の保留)
- 「最初からわかっていたらそうしていたのに、というのが口惜しい。」 (判断の誤差)
- 「そうしたかった、とは思う。」 (反問への譲歩)

文書について述べる文でも、次の四つは残してよい。

1. **反論処理**：読者の誤読・反論を「」で具体的に書き出して退ける。漠然と「誤解しないでほしい」とだけ書かない。
2. **問いの設置と回収**：境界に置く問いと、その答えを返す文。本文が何でないか、何をしないかの宣言は問いの設置ではない。
3. **読者への依頼・断り**：境界に置く、読み方についての短い依頼。
4. **例の枠の開閉**：架空の例・場面の枠を開閉する文。例が架空であることを示し、抽象的な議論から場面へ戻す機能を持たせる。

削除と書き換えは次の順で行う。

1. 文書を更新するだけの文を削除し、前後がつながるなら終える。
2. 削除で論理が飛ぶ場合は、その文が指していた内容を状況側の文に書き換える。
3. 書き換え後も本文自身を話題にしているなら、四つの例外に収まらない限り削除して前後を橋渡しし直す。

## 執筆後の点検手順

草稿を書き上げたら、次の順で点検する。

1. **話題テスト**：段落の頭の文と独立した短文を拾い、状況と文書のどちらを更新するか判定する。文書側は、四つの例外に該当しない限り削除または書き換える。推敲で新造・整形した文も直後に判定する。
2. **漏出テスト**：この規範の語彙・例文 (「答えの半分」「緊張」「回収」「線を引く」など) が本文に現れていないか検索する。現れていれば装置を宣言しているため削除し、内容の側で実現し直す。節末の「次は〜」型の進行予告も確認する。
3. **緊張台帳**：本文中で立てた問い、思い込み、約束を列挙し、それぞれの回収位置を行で指す。指せないものは回収を書き足すか、問いごと削る。
4. **拍の点検**：長い断定文が3つ以上続く箇所を探し、短い足場、停止、または根拠のある逡巡を挟む。
5. **境界の点検**：二人称の呼びかけ、依頼、謙抑が本文中盤にないか確認し、境界へ移すか削る。

## 修正指示への使い方

平坦な文章を診断するときは、症状から処方を引く。

- **全段落が同じ調子で疲れる**：文の拍がない。点検手順4を適用する。
- **正しいのに読み進める気がしない**：未回収の緊張がない。冒頭に状況から作った緊張を入れ、緊張台帳で回収位置を確認する。
- **理論の節で急に温度が下がる**：理論が違和感より先に出ている。理論の前に、資料に裏づけられた反問か判断状態を置き、列挙を場面へ着地させる。
- **緩い文はあるのに弛んで見える**：緩みが文書更新になっている。話題テストにかけ、状況側の文へ書き換える。
- **章末が説教くさい**：抽象論のまま閉じている。読者がすでに持っている具体へ着地させる。
- **冒頭が事務的**：態度のない議題表になっている。予告文に根拠のある態度を与えるか、読者の実感・抵抗を先に置く。
