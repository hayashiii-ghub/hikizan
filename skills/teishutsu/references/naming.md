# 名前の付け方

利用先リポジトリやハーネスの規約を最優先する。規約がない場合だけ次を使う。

- ブランチ、コミット、PRは、実装手段や作業者ではなく、変更する機能・Issueを同じ語彙で表す
- ブランチは短い`kebab-case`を基本にし、必要な接頭辞はリポジトリ・ハーネス規約へ従う
- コミットの件名とPRタイトルは、「何が変わるか」が分かる命令形または現在形の1文にする
- `PR-1`、`step3`など独自の連番を作らない。Issue・PR番号はホスティングサービスの番号を使う
- 件名へ手動で`(#NN)`やメールアドレスを含む共同作者情報を付けない
- 本文は差分だけでは理由が分からない場合にだけ書く

名前を付けたら、対象範囲を正しく表し、同じ目的の成果物が同じ語彙になっているか確認する。
